Records

Scores 2022–2025 · chat 2022–2026

Every score the league has ever posted, and every message it has ever sent. Renamed managers are shown under their current name.

Scores are built from Sleeper's weekly matchup results, which report final weekly totals rather than scoring as it happened — so a true in-game comeback can't be detected. I got robbed is the closest honest version: the biggest scores that still lost. Yappers counts league-chat messages per manager, keyed on user_id so a rename doesn't split anyone in two, with SleeperBot's automated waiver and matchup posts excluded. Counts only — no message text was collected. These will not match the MSGS column in Sleeper's all-time standings, and the app is the one being loose: that table is per franchise, so it hands a roster's message history to whoever owns it now. It credits Aydeng29 with 49 messages that FriscoNigga posted on roster 9 in 2022–23, before Ayden took the team over in 2024 — the same reason it shows him a 22–34 record across four seasons he didn't all play. Counted by person, Ayden has never posted.
